# Place names

Derived from GeoNames cities1000, downloaded 8 October 2026. Includes cities and settlements with at least 1,000 inhabitants and administrative seats. Columns: ASCII name, latitude, longitude, country code, population. Alternate names and other fields were removed. This is a nearby-place reference, not an administrative-boundary lookup or aviation navigation database.

Source: https://download.geonames.org/export/dump/cities1000.zip
