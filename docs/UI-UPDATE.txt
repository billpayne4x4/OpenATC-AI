OpenATC AI window controls

Build and installation
Build the Rust workspace from the project root, then install with scripts/install-rust-plugin.py and the path to X-Plane 12. See README.md for the commands. Close X-Plane before replacing its installed plugin binaries.

Header
The speech bubble opens communications, the headset opens nearby radio stations, and the clipboard opens Planning. The other page icons open Taxi, Arrival, Airports and Settings. On the right, the page-with-plus icon starts a New flight after confirmation. It clears OpenATC's plan, conversation, clearances, guidance and pending crew actions. Settings, remembered controller voices and aircraft controls are kept.

Pin keeps the window expanded. The chevron toggles the compact communications view. Pop out moves the panel into a separate simulator window. Drag the title area to move the window, or the lower-right grip to resize it.

With Pin off, Fade delay controls automatic collapse. Hovering over the panel or using push-to-talk expands it. A manually collapsed panel stays compact until the pointer leaves and returns. Recording and request editors keep it open. Drag the divider to change the space shared by the conversation and requests.

Channels
Channels lists published stations within simulated reception range. The initial filter uses the current airport; clear it to see other receivable stations. Select a station to tune COM1. Click list headers to sort in ascending or descending order. Underlined ATC frequencies in the conversation also tune COM1 when radio power is available. Airport searches remain on Airports.

Taxi
The route stops at each clearance limit. An intervening runway has its own hold-short instruction and requires an explicit crossing clearance and correct readback. Ground or Tower can issue that clearance when stopped at the hold and reported traffic is clear. Once the aircraft clears the runway, the controller gives onward taxi instructions. Taxi arrows show only accepted guidance. Existing yellow runway guard lights keep flashing; they are not clearance-controlled red stop bars.

New flight and re-enable
Use New flight to start over without disabling the plugin or restarting the AI server. The plugin now reuses its window renderer when disabled and re-enabled, avoiding a second active ImGui context. Live simulator reset and re-enable still need user acceptance testing.
