OpenATC AI — ATC window update

Installation
Extract this archive into your existing project root, next to your root Cargo.toml, allowing its crates/ files to replace the existing files. Keep the new crates/ui/assets/fonts/ directory: the font is embedded at compile time. Rebuild and install the plugin using your existing build/install workflow. This is a source archive, not a compiled lin.xpl.

The uploaded archive did not contain the root Cargo.toml or Cargo.lock. Your existing workspace files are required and are not replaced by this update.

Controls
The speech bubble opens communications, the headset opens airport frequencies, and the clipboard opens the flight plan. The menu opens Taxi, Arrival, Airports and Settings. The right-hand controls pin the expanded view, toggle communication-only mode, and pop the plugin window out or return it to the simulator. Drag the blank/title area of the toolbar to move the in-simulator window.

Unpin the window to enable automatic communication-only mode after the existing Fade delay. Hovering over the window or using push-to-talk expands it again. A manually collapsed window remains compact until the pointer leaves and returns. Draft messages, request editors and recording keep the controls open. The divider between the transcript and request controls changes their relative heights.

On the frequency page, load the required airport and select a station to tune COM1. Radio power must be available. The desktop preview displays frequencies; tuning is performed by the simulator plugin. Existing copilot settings still govern automatic tuning.

Implementation
- Correct panel bounds and consistent drawing/mouse coordinates.
- X-Plane projection, modelview and viewport datarefs account for display scaling and window placement.
- Custom resizable header with vector icons and tooltips.
- White pilot messages, blue controller messages and distinct crew badges.
- Full-width, scrolling request rows and an adjustable transcript divider.
- Expanded/compact window heights and background opacity transitions.
- Embedded DejaVu Sans, rasterised at higher resolution; the font licence is included.
- Matching desktop font and layout scaling.
- Correct ImGui guard lifetimes for tabs, tables and the audio-device dropdown.
- Request/voice editors and reset confirmation remain within the plugin panel.
- Debounced saving of the existing UI/settings fields.
- Text input uses the supplied character rather than converting the virtual-key code to text.
